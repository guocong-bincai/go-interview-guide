# Top 20 高频算法题（按面试频率排序）

> 目标：帮助零基础或基础薄弱同学，优先掌握最常被问到的算法题。
>
> 规则：
> - 按真实面试高频程度排序，越靠前越常问
> - 每题至少提供 **两种解法**
> - 每题都讲清楚 **考点 / 思路 / 易错点 / Go + Python 双语代码**
