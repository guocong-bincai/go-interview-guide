# 39. 路径总和 III（Path Sum III）

> 频率：★★★☆☆  难度：中等  LeetCode 437

## 小白先理解
问的是：二叉树里有多少条“向下走”的路径，它们的和等于 targetSum。
不要求从根开始，也不要求到叶子结束。

## 解法一：枚举每个节点作为起点
- 对每个节点向下 DFS
- 时间较高

## 解法二：前缀和 + DFS（推荐）
### 核心思路
和数组前缀和很像：
如果当前前缀和是 `cur`，之前某个前缀和是 `cur-target`，那么中间这段路径和就是 target。

## 一句话记忆
**路径总和 III = 树上的前缀和。**
