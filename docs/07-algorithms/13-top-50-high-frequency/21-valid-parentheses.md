# 21. 有效括号（Valid Parentheses）

> 频率：★★★★☆  难度：简单  LeetCode 20

## 题目描述
给定一个只包括 `(`，`)`，`{`，`}`，`[`，`]` 的字符串，判断字符串是否有效。

有效字符串需满足：
- 左括号必须用相同类型的右括号闭合
- 左括号必须以正确的顺序闭合

## 面试为什么爱问
- 这是栈的经典应用，属于高频入门题
- 考的是"后进先出"思维：最近匹配的括号先处理
- 面试官常追问：如何处理 `"([)]"` 这种中间交叉的情况

## 核心考点
- [ ] 栈的使用
- [ ] 括号匹配逻辑
- [ ] 边界条件：空串、只有左括号、只有右括号

## 小白先理解
**本质：找配对**

想象你是个接待员，遇到左括号（客人进门）就登记；遇到右括号（客人要走）就看最近登记的人能不能配对。

比如 `"({[]})"`：
- 进：`(`、`{`、`[` → 栈：[`(`, `{`, `[`]
- 出：先是 `]` 配对 `[`，再是 `}` 配对 `{`，最后是 `)` 配对 `(` → 全部配对 ✅

如果遇到右括号时栈为空，或者栈顶不匹配 → 直接失败。

---

## 解法一：栈（推荐）

### 思路
遍历字符串：
- 遇到左括号 → 入栈
- 遇到右括号 → 栈顶匹配？弹出 / 不匹配？直接 false

最后栈为空才算成功。

### Go
```go
func isValid(s string) bool {
    stack := make([]byte, 0, len(s))
    pairs := map[byte]byte{')': '(', ']': '[', '}': '{'}

    for i := 0; i < len(s); i++ {
        ch := s[i]
        if ch == '(' || ch == '[' || ch == '{' {
            stack = append(stack, ch) // 左括号入栈
        } else {
            // 右括号：栈空或不匹配 → 失败
            if len(stack) == 0 || stack[len(stack)-1] != pairs[ch] {
                return false
            }
            stack = stack[:len(stack)-1] // 配对成功，弹出
        }
    }

    return len(stack) == 0 // 栈空说明全部配对成功
}
```

### Python
```python
def isValid(s: str) -> bool:
    stack = []
    pairs = {')': '(', ']': '[', '}': '{'}

    for ch in s:
        if ch in '([{':
            stack.append(ch)
        else:
            if not stack or stack[-1] != pairs[ch]:
                return False
            stack.pop()
    return len(stack) == 0
```

### 复杂度
- 时间：O(n)，每个字符只遍历一次
- 空间：O(n)，最坏情况全存左括号

## 易错点
| 错误写法 | 问题 |
|---------|------|
| 用 `map[byte]byte{...}` 直接比较 | 右括号做 key 时找不到会 panic |
| 最后用 `return true` 不检查栈 | `"([ "` 这种只有左括号的情况会漏 |
| 用 `strings.Replace` 反复替换 | O(n²) 且治标不治本 |

## 面试追问

**Q：如果是多线程环境，怎么保证线程安全？**
栈本身不是线程安全的。如果并发访问，需要加锁（`sync.Mutex`）或使用 `sync.Stack`（但 Go 的 sync 包没有 Stack，自己实现或用 channel 模拟）。

**Q：如果要返回具体哪里不匹配，怎么做？**
除了返回 true/false，返回不匹配字符的索引位置。可以在匹配失败时记录 `i` 并返回。

**Q：如何处理 `"([)]"` 这种"看起来像配对但实际不配对"的情况？**
栈天然能处理！因为 `"([)]"` 的处理顺序是：`(`, `[`, 然后遇到 `)` → 栈顶是 `[` 不匹配 `)` → 返回 false。这是栈优于简单计数器的关键区别。
