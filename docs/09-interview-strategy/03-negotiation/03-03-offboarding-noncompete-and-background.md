# 离职流程、竞业协议与背景调查应对

> 考察频率：★★★★☆（拿 Offer 后最容易翻车的一环）  难度：★★★★☆
> 适用：Offer 到手 → 入职前的过渡期

---

## 核心答案（30 秒版）

拿到 Offer 不代表结束，**离职流程 + 竞业 + 背调**这三关才是"最后一公里"。核心原则：**交接做干净（专业度）、竞业看清楚（法律风险）、背调说实话（诚信）**。尤其竞业协议，2026 年 AI/技术行业"竞业扩大化"明显，普通程序员也被追责，**入职时就要读懂条款，离职时确认是否启动，入职下家前评估冲突**。记住三个动作：**① 提前一个月书面提离职；② 确认竞业是否启动、补偿是否到账；③ 背调信息保持真实且前后一致。**

---

## 1. 离职流程的完整时间线

```
拿到书面 Offer（确认薪资/入职时间/背调授权）
   ↓
书面提离职（邮件 + 口头，提前 30 天；试用期提前 3 天）
   ↓
交接期（文档化 + 当面交接 + 上级确认）
   ↓
确认竞业是否启动（关键！）
   ↓
办理离职手续（工作交接单、资产归还、离职证明）
   ↓
背调（下家或第三方背调公司发起）
   ↓
入职下家
```

### 1.1 提离职的注意事项

```
✅ 一定要书面（邮件 best），写明"离职申请 + 最后工作日"
✅ 提前 30 天（《劳动合同法》第 37 条），协商一致可提前
✅ 先跟直属上级口头沟通，再走正式邮件流程
✅ 交接文档化：系统架构、账号权限、待办事项、联系人
❌ 不要只口头说、不要突然消失、不要删代码/带走数据
❌ 不要在离职前后说公司坏话（会被背调）
```

**为什么书面很重要**：口头离职容易扯皮"你什么时候提的"，书面记录是保护你自己的证据。同时，交接做得好，**离职证明和背调评价都会顺畅**。

### 1.2 交接清单（5~8 年工程师版）

```
□ 系统架构图 & 核心链路说明
□ 在维护的服务清单 + 部署/回滚文档
□ 账号权限移交（含生产环境、监控、告警）
□ 未完成需求的状态和风险说明
□ 重要对接人清单（上下游、外部依赖方）
□ 线上故障预案 & 值班安排
```

## 2. 竞业协议：程序员最容易踩的坑

### 2.1 竞业协议的三个环节

一份竞业协议要真正"生效"，通常要同时满足**签署、启动、支付**三步：

| 环节 | 说明 |
|------|------|
| **签署** | 入职时签（多数公司是入职必选项，注意条款内容） |
| **启动** | 离职时由业务主管/HR 决定是否对你启动竞业 |
| **支付** | 离职后公司按月支付补偿金，竞业限制才正式生效 |

**关键点**：签了协议 ≠ 一定被启动；但**一旦公司启动并支付补偿，你就受约束**。如果公司**连续 3 个月不支付补偿金**，员工可以主张解除竞业限制（具体以当地司法解释为准）。

### 2.2 法律要点（了解即可，具体案件找律师）

```
《劳动合同法》第 24 条：竞业限制人员限于
  ① 高级管理人员 ② 高级技术人员 ③ 其他负有保密义务的人员
  竞业期最长不超过 2 年

补偿标准：一般不低于离职前 12 个月平均工资的 30%（各地有差异）
违约金：通常由协议约定，可能是年薪的数倍（几十万到上百万）

最高法指导性案例 190 号：
  判断是否构成"竞争关系"，不能只看营业执照经营范围，
  要结合①实际经营内容 ②服务对象/产品受众 ③对应市场是否重合 综合审查
```

⚠️ 现实：据统计，近年竞业纠纷中约 **79% 的义务主体是"其他负有保密义务的人员"**，其中七成是基层员工。**即普通程序员/产品经理也可能被追责**，不能想当然认为"跟我没关系"。

### 2.3 离职前必做的竞业自查

```
□ 我入职时签的竞业协议，竞对公司名单有哪些？地域范围？期限？
□ 补偿金标准是多少？公司是否明确表示不启动？
□ 我下家是否在竞对公司名单内？是否从事同类业务？
□ 如果启动竞业，我能不能承受"不工作/转行"这段时间？
□ 收到过竞业补偿金吗？不认可的话要不要主动退回？
```

### 2.4 争议时的自我保护动作（务必先咨询律师）

```
1. 不签"不签就不给离职证明"的胁迫文件——离职手续是你的权利
2. 公司未按时支付补偿金：保留银行流水证据，可主张解除
3. 收到补偿金但不认可竞业：谨慎处理（退回/协商，别默认收下等于认账）
4. 下家帮忙兜底时（有些公司会承诺代赔/法务支持）：白纸黑字写进合同
5. 所有沟通留书面记录（邮件/聊天），别只在电话里说
6. 竞业期内别留"跑竞对"的铁证（工牌、工区视频、社保记录都可能成为证据）
```

> ⚠️ 以上仅为常识梳理，**不构成法律意见**。真遇到竞业纠纷，第一件事是找专业劳动法律师。

## 3. 背景调查（背调）应对

### 3.1 背调查什么

| 项目 | 内容 | 雷区 |
|------|------|------|
| **身份/学历** | 身份证、学历学位真伪 | 学历造假（一查一个准） |
| **工作经历** | 任职时间、职位、离职原因 | 时间对不上、职级夸大 |
| **工作表现** | 前上级/同事评价、绩效 | 与前上级关系差 |
| **薪资** | 有时会核（需授权） | 报高太多 |
| **竞业/诉讼** | 是否有竞业约束、劳动纠纷 | 隐瞒竞业 |

### 3.2 背调原则：真实 + 一致 + 授权

```
✅ 简历、面试口径、背调信息三者必须一致（时间/职位/薪酬）
✅ 提前和前上级打好招呼（礼貌说明，请求支持）
✅ 真实回答，明显夸大（如"主导"说成"总负责"）风险极高
✅ 背调必须经你授权；未经授权可以拒绝
❌ 不要伪造学历/履历（这是硬性红线，可被直接辞退且无赔偿）
❌ 不要隐瞒竞业（背调+社保很容易查到）
```

### 3.3 和前上级的关系维护

- 离职时：**把交接做好、把关系处好**（背调时他会帮你说话）
- 离职后：**逢年过节问候、朋友圈点个赞**，别"人走茶凉"
- 如果和前上级关系确实差：**提前告知下家 HR**，并提供一个可以佐证的替代推荐人（如跨部门合作方）

## 4. 试用期与入职衔接

```
✅ 确认 Offer 的"入职时间"与"离职交接"衔接好（别出现社保空窗）
✅ 入职前把背调材料、离职证明、体检报告准备齐
✅ 入职后快速熟悉团队/系统，主动要文档、找 mentor
⚠️ 试用期被"优化"：合法需 N+1（满 1 个月以上），违法可仲裁 2N
⚠️ 保留所有书面证据（绩效/沟通记录），必要时咨询律师
```

## 高频追问

### Q: 公司不给我开离职证明怎么办？
> 出具离职证明是公司的法定义务（《劳动合同法》第 50 条）。如果拒开，可以向劳动监察部门投诉，或申请劳动仲裁。同时保留你已提出离职、已完成交接的书面证据。"不开证明就不给办"是常见施压手段，别被唬住。

### Q: 我签了竞业但公司没提，是不是就没事？
> 只要公司**没启动 + 没支付补偿**，通常不构成实际约束。但保险起见，离职时最好让 HR/主管**书面确认不启动竞业**，避免日后扯皮。

### Q: 背调时前上级说我坏话怎么办？
> 首先自查是不是确有其事；其次可以提前向下家说明特殊情况，并提供其他推荐人佐证；如果构成诽谤且造成实际损失，可依法维权。多数正规背调会多方交叉验证，单一负面评价不致命。

### Q: 竞业协议签了但补偿很低（比如 10% 工资）有效吗？
> 补偿标准低于法定/地方标准的条款可能被认定部分无效或可调整，但**签了字仍需谨慎对待**。具体要看当地规定和协议内容，建议咨询律师，不要自行认定"无效"就跳竞对。
