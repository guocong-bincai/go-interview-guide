# 简历投递渠道与内推、猎头沟通策略

> 考察频率：★★★★☆（求职周期必备）  难度：★★☆☆☆
> 适用：简历定稿后到拿面试邀约之间的关键一环

---

## 核心答案（30 秒版）

简历写得好，投不进去也白搭。5~8 年工程师拿面试的主渠道排序是：**内推 ＞ 猎头 ＞ 官方社招 ＞ 招聘平台海投**。内推的核心不是"找人递简历"，而是拿到**靠谱的部门级内推人**（能看到进度、能捞简历、能说上话）；猎头的核心是**把猎头当信息源而非救命稻草**（用猎头换薪资带宽、团队口碑、岗位真实信息）。投递节奏上先小范围试水（1~2 家非目标公司）验证简历转化率，再集中投目标公司，避免"好机会被投废"。

---

## 1. 四大投递渠道对比

| 渠道 | 转化率 | 进度可见性 | 适合场景 | 坑 |
|------|--------|-----------|---------|-----|
| **内推** | 最高（5~20 倍于海投） | 高（内推人可查流程） | 有人脉的目标公司 | 内推人是否真能"捞"简历 |
| **猎头** | 中高 | 中（猎头帮跟进） | 5 年以上、薪资敏感的岗位 | 猎头只关心成交，信息可能美化 |
| **官方社招通道** | 中 | 低（大多石沉大海） | 无内推的备选 | 简历进入公共池，响应慢 |
| **招聘平台（Boss/脉脉/拉勾）** | 中低 | 中 | 中小公司、快速试水 | 岗位质量参差、HR 已读不回 |

**核心判断**：
> 一家公司如果**能内推就绝不海投**。同一份简历，内推进入的是"内推简历池"，HR 和用人部门会优先看；海投进入的是公共池，两个池子的响应率和优先级完全不是一个量级。

## 2. 内推的正确打开方式

### 2.1 找什么样的内推人

```
✅ 最优：目标部门/目标组在职员工（能直接把简历丢给 hiring manager）
✅ 次优：目标公司其他部门员工（能进内推池，但可能到不了目标组）
⚠️ 一般：只在社交平台发内推码的陌生人（本质等于"换个池子海投"）
❌ 无效：已离职员工 / 只说"帮你投一下"但不跟进的人
```

**判断内推人是否靠谱的三个问题**：
1. 你能看到我的投递进度吗？（能不能查流程）
2. 简历如果被卡，你能帮忙问一下原因吗？
3. 你知道这个岗位现在还有 HC 吗、面试官关注什么吗？

### 2.2 内推话术模板

```
X 哥/姐你好，我是 XX（一句话身份：X 年 Go 后端，目前在 XX 公司做 XX）。
看到你们团队在招 XX 岗位，和我的经历比较匹配：
- 主导过日均 XX 万订单的交易系统，P99 XX ms
- 熟悉 Go 并发/分布式事务，有 XX 实战经验
方便的话想请你帮忙内推一下，简历我发你。不管成不成，感谢！
如果有岗位更细的要求（比如更偏 XX 方向），也麻烦你帮我看看怎么调整简历。
```

**要点**：一句话身份 + 2~3 条匹配点 + 明确诉求 + 给对方台阶。不要一上来甩简历让他自己想。

### 2.3 时间点选择

- 内推要趁**岗位刚放出**（越早，HC 越充足，面试官越有耐心）
- **避开部门大促/发版前**（面试官没空，约面会拖）
- 投递后**2~3 天没动静就礼貌催一次**，别每天问

## 3. 猎头沟通策略

### 3.1 猎头对你的真实价值

猎头不是"帮你找工作的贵人"，而是一个**信息中介**。用好猎头的方式：

```
✅ 问薪资带宽：这个岗位的薪资范围、几薪、股票结构
✅ 问团队口碑：面试官背景、团队规模、汇报关系、近期是否有大变动
✅ 问岗位真实性：是不是"萝卜岗"（已经内定人）、是不是新开的 HC
✅ 让猎头帮改简历表述（对标 JD 的关键词）
❌ 不要全信猎头的话：他为了成交会夸大机会、淡化风险
```

### 3.2 判断猎头是否专业

| 专业猎头 🟢 | 不专业猎头 🚩 |
|------------|--------------|
| 先问你的技术方向和期望 | 上来就是"有个好机会你发个简历" |
| 能说清岗位的具体技术栈和团队 | 只会念 JD，问细节就"我帮你问问" |
| 提醒你面试注意事项、帮你 mock | 面完就消失，只在要结果时出现 |
| 尊重你的节奏，不逼你跳 | 天天催你"这周必须给答复" |

### 3.3 和猎头谈判的三个要点

1. **不要过早暴露底牌**：猎头问你当前薪资时，可以给"总包范围 + 期望涨幅"，不必给精确到个位数的月薪。
2. **让猎头去谈、你只给锚点**：谈薪阶段让猎头当"传声筒"，避免你和 HR 直接硬碰。
3. **多家猎头别报同一家**：同一家公司通过多个猎头投递，会互相冲突，反而掉好感。

## 4. 投递节奏与"试水"策略

### 4.1 分批次投递

```
第 1 批（试水 1~2 家，非目标公司）
  → 验证简历转化率、熟悉面试节奏、暴露知识盲区
  → 拿到反馈后立刻修简历、补短板

第 2 批（目标公司 A 级，3~5 家）
  → 简历已打磨、话术已熟练，状态最好的时候投

第 3 批（保底 B 级 + 补投）
  → 确保有兜底 Offer，谈判时更有底气
```

### 4.2 投递节奏的坑

```
❌ 一次性海投 30 家 → 面试撞车、精力分散、好公司反而没准备好
❌ 心仪公司第一个投 → 没准备好就浪费了机会（大厂多有冷冻期 6~12 个月）
❌ 长期断档 → 面试手感会退化，超过 2 周没面试要警惕
✅ 保持每周 1~2 场面试的稳定节奏，直到拿到满意的 Offer
```

⚠️ **冷冻期**：大厂面试失败后通常有 **6~12 个月冷冻期**，期间无法再投。所以**最重要的目标公司要放在状态最好的时候投**，不要用它来练手。

## 5. 投递后的跟进

| 时间 | 动作 |
|------|------|
| 投递后 2~3 天 | 通过内推人/猎头确认简历是否被查看 |
| 面试后 24h 内 | 发感谢邮件（简短：感谢 + 重申匹配点 + 期待反馈） |
| 面试后 3~5 天 | 没反馈就礼貌询问结果与预计时间线 |
| 拿到 Offer 后 | 明确答复期限，用它去推进其他流程 |

**跟进话术（邮件/消息）**：
> "X 老师您好，我是 X 月 X 日面试 XX 岗位的 XX。感谢上次的交流，我对团队做的 XX 方向非常感兴趣。想跟您确认下后续流程大概的时间安排，方便我协调其他安排。感谢！"

## 高频追问

### Q: 没有大厂人脉，怎么找内推？
> 三条路：① 脉脉/LinkedIn 搜目标公司员工，礼貌私信（说明来意 + 简洁履历）；② 技术社区（Go 夜读群、掘金、GitHub）里认识的人；③ 前同事/同学的同学。记住：内推是"请求"，姿态要低但要专业，对方给不给是情分。

### Q: 简历投了没回音，是简历问题还是渠道问题？
> 先排除渠道：如果内推也没回音，基本是简历问题（关键词不匹配 / 经历描述太空 / 级别不对）。修简历优先级高于换渠道。

### Q: 猎头说帮我保密投递，还说对方很急，能信吗？
> "急招"往往是套路，用来催你做决定。保密投递可以接受，但要问清楚：投了几家、是哪几家、有没有和你现在公司有竞业冲突。"很急"不构成你仓促决定的理由。

### Q: 通过内推进去，如果面试表现差，会连累内推人吗？
> 轻微会。内推人是"背书"，候选人太差会让内推人尴尬。所以：尊重内推人给你的机会，认真准备，即使没过也主动向对方说明和致谢，保持长期关系。
